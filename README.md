# pdftotxt-pgp-aws-services
A serverless AWS Lambda function that converts PDF files to text and applies PGP encryption/decryption operations.

## Overview

This Lambda function provides PDF to text conversion capabilities with integrated PGP encryption support, designed to run in AWS serverless environment.

## Features

- PDF to text extraction
- PGP encryption/decryption
- Serverless architecture
- AWS Lambda runtime optimized

## Prerequisites

- AWS CLI configured
- Node.js/Python runtime (depending on implementation)
- PGP keys for encryption operations

## Deployment

Deploy using AWS SAM, Serverless Framework, or direct Lambda deployment methods.

## Usage

Trigger the function with PDF files as input to receive encrypted text output.

## Environment Variables

Configure required environment variables for PGP keys and AWS service access.
